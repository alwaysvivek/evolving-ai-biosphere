🌍 Evolving AI Biosphere: Definitive Manual

A research-grade simulation combining Multi-Agent Reinforcement Learning (MARL), Genetic Algorithms, and Large Language Models (LLM) in an open-ended continuous environment.

🚀 Quick Start

1. ./setup_env.sh (Install dependencies)

2. python3 launch_services.py (Start MLflow & Monitor Ollama)

3. python3 simulation.py (Run the simulation)

1. System Architecture

The system is composed of three decoupled layers: The Control Plane, The Simulation Core, and The Intelligence Layer.

2. Entity Biology & Mechanics

🌱 Plants (Producers)

Plants are static entities that generate energy from the environment.

  • Photosynthesis: Energy += 3.5 * GlobalLight * LocalLightMap * TempFactor.
    Note: Light Map is a Perlin noise field; some tiles are naturally darker.
  • Reproduction: Asexual. Requires Energy > 130. Splits parent energy by 50% to spawn offspring in adjacent empty tile.
  • Global Cap: Limited to 700 entities to prevent memory overflow (CPU constraint).

🐑 Herbivores (Consumers - Genetic)

Herbivores evolve individually via Genetic Algorithms. They have a simple Feed-Forward Neural Network brain.

  • Metabolism: Burn energy to move. Base cost 1.0/tick.
  • Action Space: Move (Up/Down/Left/Right), REST, or EAT.
  • "Solar Basking": Uniquely, if a Herbivore chooses REST, it gains energy: 6.0 * Light * TempFactor. This is an intentional survival mechanic allowing them to survive plant famines if they stay still in sunlight.
  • Evolution: Upon reproduction (Energy > 120), offspring inherit weights with `0.05` Gaussian Mutation. This selects for efficient foraging strategies.

🐺 Predators (Consumers - Reinforcement Learning)

Predators share a Collective Hive Mind (single LSTM model). They do not evolve individuals; the species learns.

  • Algorithm: Policy Gradient (REINFORCE).
  • Inputs (8): Vision vectors to nearest Plant, Herbivore, Wall, and Ally.
  • Reward Signal:
    • +1.0 for moving towards prey.
    • min(TargetEnergy * 1.5, 120) for EATING prey.
    • -0.1 per tick (Starvation penalty).
    • -5.0 for Death.
  • Training: Happens every 20 generations asynchronously.

The system uses Function Calling to parse these intents and execute the corresponding Simulation API methods.

🧠 Under the Hood: LangChain vs. LangGraph

The Intelligence Layer uses two distinct frameworks for different tasks:

  • LangChain (Direct Control): Used for the standard "God Mode" chat. It simply binds the Llama 3.2 model to a list of Python functions (tools). When you type "Spawn predators", the model returns a structured JSON tool call, which LangChain invokes directly.
  • LangGraph (The Council): Used for the advanced "Summon Council" feature. This runs a State Graph workflow:
    Node 1 (Gaia) proposes a life-preserving action.
    Node 2 (Entropy) critiques it and suggests chaos.
    Node 3 (Arbiter) weighs both arguments and makes the final decision.
    This Multi-Agent Debate is impossible with a simple chain and requires LangGraph's cyclic/stateful architecture.

3. Environmental Physics

The world is not static; it has invisible layers of physics.

  • Scent Trails (Pheromones):
    • Plants and Herbivores leave invisible "scent" values in their grid cells.
    • Diffusion: Scents spread to neighbors every tick.
    • Decay: Scents fade by factor 0.85 per tick.
    • Predators use this gradient to track prey that is out of line-of-sight.
  • Temperature & Light: Global variables that sine-wave over time, affecting metabolic rates and growth.

4. God Mode & Controls

Interact with the simulation using LLM commands or Hotkeys.

⌨️ Hotkeys

  • SPACE: Pause/Resume.
  • E (Scarcity Event): Instantly reduces ALL plant energy by 75% and growth chance by 80%. Simulates a sudden drought.
  • K / L / P: Extinction events (Kill All Predators / Herbivores / Plants).
  • T: Toggle Predator Training (useful to freeze a smart model).
  • R: Generate text report in console.

🤖 Natural Language (God Mode)

Type into the sidebar input box to command the world. The God Mode Agent (Llama 3.2 on Ollama) parses your text into function calls.

"Spawn a spiral galaxy of nutrients in the center"
"Kill 40% of the herbivores"
"Make the world colder (-0.2 temp)"

5. Services

  • MLflow (Port 5001): Logs `avg_energy`, `population`, `diversity_score` to a dashboard.
  • Ollama (Port 11434): Local inference server for the God Mode agent.
