## Section 3: Technical Architecture

### Core Systems Overview

The simulation is built on five interconnected subsystems:

1. **Neural Network Agents** (LSTM policies for decision-making)
2. **Cellular Grid System** (spatial world representation)
3. **Energy Economy** (resource flow and metabolism)
4. **Chemical Signaling** (scent diffusion for indirect perception)
5. **Reinforcement Learning** (hive mind training pipeline)

---

### Neural Network Architecture

#### **Herbivore/Plant LSTM (CellLSTM)**

**Purpose:** Per-organism neural network for individual decision-making.

**Architecture:**
```
Input Layer: 8 neurons
  - plant_count (0-1)
  - herbivore_count (0-1)
  - predator_count (0-1)
  - nutrient_count (0-1)
  - energy_level (0-1)
  - age_factor (0-1)
  - random_noise_1
  - random_noise_2

Hidden Layer: LSTMCell (32 hidden units)
  - Maintains internal state (h, c) across timesteps
  - Enables temporal decision-making

Output Layer: Linear (32 → 4 neurons)
  - Softmax activation for action probabilities
  - Actions: [reproduce, move, rest, default]
```

**Weight Initialization:**
- Xavier uniform for weight matrices
- Zero initialization for biases

**Mutation Mechanism:**
During reproduction, offspring neural networks undergo random perturbations:
- 2% probability per weight
- Gaussian noise with σ=0.01
- Preserves general behavior while enabling evolutionary drift

**State Management:**
Each organism maintains its own (h, c) hidden state that persists across decision cycles, allowing memory of previous observations.

---

#### **Predator Hive LSTM (PredatorHive)**

**Purpose:** Shared policy network used by all predators collectively.

**Architecture:**
```
Input Layer: 8 neurons (same observation space as CellLSTM)

Hidden Layer: LSTMCell (64 hidden units)
  - Fresh hidden state per forward pass during training
  - No persistent state during inference (stateless execution)

Output Layer: Linear (64 → 4 neurons)
  - Actions: [reproduce, move, rest, hunt]
```

**Key Difference from CellLSTM:**
- Single network shared across ALL predators
- No per-organism state maintenance
- Training uses batched experiences from entire population

**Forward Pass Logic:**
```python
# Inference (during simulation)
h0, c0 = zeros(batch_size, 64)  # Fresh state
h, c = LSTMCell(observation, (h0, c0))
logits = Linear(h)
probs = softmax(logits)
action = sample(probs)  # Stochastic action selection
```

**Training Pipeline:**

1. **Experience Collection:**
   - Every predator action generates tuple: `(observation, action_index, reward)`
   - Stored in global `hive_experiences` list
   - Reward = energy gained from hunt (0 for non-hunt actions, up to 120 for successful kills)

2. **Training Trigger:**
   - Occurs every `TRAIN_INTERVAL` generations (default: 20)
   - Requires minimum `MIN_EXPERIENCES_TO_TRAIN` samples (default: 16)

3. **REINFORCE Algorithm:**
```
For each experience (s, a, r):
  1. Normalize rewards: r_norm = (r - mean(R)) / std(R)
  2. Compute log probability: log_π(a|s)
  3. Compute loss: L = -mean(log_π(a|s) · r_norm)
  4. Backpropagate and update weights
```

4. **Hyperparameters:**
   - Learning rate: 1e-3
   - Epochs: 8 per training cycle
   - Batch size: 64
   - Optimizer: Adam

**Advantage of Shared Network:**
- Predators learn from collective experience
- Rare successful strategies spread instantly to all individuals
- No need for explicit communication—learning IS the communication
- Faster convergence than per-organism evolution

### Q-Learning Agents (Legacy System)

**Note:** Q-learning agents are implemented but currently not actively used for primary decision-making. They serve as a fallback/compatibility layer.

**State Representation:**
```python
state_key = (
  clamp(plant_count, 0, 3),
  clamp(herbivore_count, 0, 3),
  clamp(predator_count, 0, 3),
  clamp(energy_bin, 0, 3)
)
```
Creates a discrete state space of 4^4 = 256 possible states.

**Q-Table Structure:**
```
Q[(state, action)] → expected_reward
```

**Update Rule (Temporal Difference):**
```
Q(s,a) ← (1-α)·Q(s,a) + α·(r + γ·max_a' Q(s',a'))

Where:
  α = learning_rate = 0.2
  γ = discount_factor = 0.9
  ε = exploration_rate = 0.15
```

**Action Selection:**
- 85% exploitation (choose max Q-value action)
- 15% exploration (random action)

### Chemical Signaling (Scent System)

**Purpose:** Enables indirect perception—organisms detect resources/threats beyond direct adjacency.

**Scent Source Calculation:**
```python
For each cell (x, y):
  if cell.type == PLANT:
    plant_scent[x, y] = 1.0 + (cell.energy / cell.max_energy)
  
  if cell.type == HERBIVORE:
    herbivore_scent[x, y] = 1.0 + (cell.energy / cell.max_energy) * 0.9
```

**Diffusion Algorithm:**
```python
def diffuse_once(grid, decay=0.85):
  new_grid = grid * decay
  
  for each cell (x, y):
    share_amount = grid[x, y] * (1 - decay) * 0.25
    
    for each neighbor (nx, ny):
      new_grid[nx, ny] += share_amount
  
  return new_grid

# Applied iteratively
for _ in range(3):  # scent_diffuse_steps
  plant_scent = diffuse_once(plant_scent, 0.85)
  herbivore_scent = diffuse_once(herbivore_scent, 0.85)

# Normalize to 0-1 range
plant_scent = plant_scent / max(plant_scent)
herbivore_scent = herbivore_scent / max(herbivore_scent)
```

**Properties:**
- **Decay Rate (0.85):** 15% of scent intensity lost each diffusion step
- **Diffusion Steps (3):** Scent spreads 3 cells outward from source
- **Share Factor (0.25):** Remaining intensity distributed equally to 4 neighbors
- **Normalization:** Final values scaled to 0-1 for consistent perception

**Usage in Decision-Making:**

*Herbivore Movement:*
```python
For each candidate tile:
  score = plant_scent[tile] - predator_penalty * 0.7 + noise
  
  predator_penalty = count_predators_within_radius(tile, radius=2)
  
Choose tile with maximum score
```

*Predator Hunting:*
```python

  value = herbivore_scent[tile]

Choose tile with maximum herbivore scent
```


**Effects:**

- Plants in dark zones (light < 0.18) suffer energy penalties and increased death risk
- Drives spatial heterogeneity in ecosystem structure

### Predator Escape Algorithm (Herbivores)

**Problem:** When predators are adjacent, herbivores must choose the safest escape route.

**Solution:** Evaluate each potential tile by counting predators within 2-cell radius, weighted by distance.

```python
def choose_escape_tile(pos):
  candidates = neighbors(pos) + [pos]  # Include staying
  best_tile = pos
  best_score = infinity
  
  for candidate in candidates:
    if candidate occupied (except self):
      continue
    
    danger_score = 0
    for dx in range(-2, 3):
      for dy in range(-2, 3):
        check_pos = (candidate.x + dx, candidate.y + dy)
        if cell_at(check_pos).type == PREDATOR:
          distance = max(abs(dx), abs(dy))
          danger_score += 3.0 / (distance + 1)
    
    if danger_score < best_score:
      best_score = danger_score
      best_tile = candidate
  
  return best_tile
```

**Weighting Logic:**
- Predator at distance 0: +3.0 danger
- Predator at distance 1: +1.5 danger
- Predator at distance 2: +1.0 danger

**Effect:** Herbivores flee toward tiles with minimum predator density, creating emergent herd behavior and strategic positioning.

### Training System (Predator Hive)

**Training Trigger Conditions:**
```python
if generation % TRAIN_INTERVAL == 0 and len(hive_experiences) >= MIN_EXPERIENCES_TO_TRAIN:
  train_hive()
```

**Default Parameters:**
- `TRAIN_INTERVAL = 20` (train every 20 generations)
- `MIN_EXPERIENCES_TO_TRAIN = 16` (minimum data requirement)

**REINFORCE Algorithm Implementation:**

```python
def train_from_experiences(experiences, lr=1e-3, epochs=8, batch_size=64):
  # Extract components
  observations = [exp[0] for exp in experiences]
  actions = [exp[1] for exp in experiences]
  rewards = [exp[2] for exp in experiences]
  
  # Normalize rewards (advantage estimation)
  rewards_mean = mean(rewards)
  rewards_std = std(rewards)
  normalized_rewards = (rewards - rewards_mean) / (rewards_std + 1e-6)
  
  # Convert to tensors
  X = tensor(observations)  # shape: (N, 8)
  A = tensor(actions)       # shape: (N,)
  R = tensor(normalized_rewards)  # shape: (N,)
  
  optimizer = Adam(hive.parameters(), lr=lr)
  
  for epoch in range(epochs):
    # Shuffle data
    permutation = random_permutation(N)
    
    for batch_start in range(0, N, batch_size):
      batch_indices = permutation[batch_start:batch_start+batch_size]
      x_batch = X[batch_indices]
      a_batch = A[batch_indices]
      r_batch = R[batch_indices]
      
      # Forward pass
      logits = hive.forward_logits(x_batch)  # (B, 4)
      log_probs = log_softmax(logits, dim=-1)
      
      # Select log probabilities of chosen actions
      chosen_log_probs = log_probs[range(B), a_batch]
      
      # REINFORCE loss: maximize expected reward
      loss = -mean(chosen_log_probs * r_batch)
      
      # Backpropagation
      optimizer.zero_grad()
      loss.backward()
      optimizer.step()
  
  # Clear experience buffer after training
  experiences.clear()
```

**Why REINFORCE Works Here:**
- **Credit Assignment:** Rewards directly indicate action quality (high reward = good hunt)
- **Policy Gradient:** Increases probability of high-reward actions, decreases probability of low-reward actions
- **Normalization:** Prevents reward scale from dominating gradients
- **Shared Network:** All predators benefit from any individual's discoveries

**Learning Progression:**
- **Early Generations (0-50):** Random exploration, inconsistent hunting
- **Mid Generations (50-200):** Hive learns to follow herbivore scent, basic pursuit
- **Late Generations (200+):** Advanced strategies emerge (ambush, territorial control, prey selection)

**Species Diversity Score:**

```python
def species_diversity_score():
  # Count organisms per species
  counts = {PLANT: n_plants, HERBIVORE: n_herbs, PREDATOR: n_preds}
  total = sum(counts.values())
  
  # Calculate frequencies
  frequencies = [counts[species] / total for species in (PLANT, HERB, PRED)]
  
  # Shannon entropy
  H = -sum([f * log(f) for f in frequencies if f > 0])
  
  # Normalize to 0-1 (max entropy = log(3))
  diversity = H / log(3)
  
  return diversity
```

**Diversity Interpretation:**
- **1.0:** Perfect balance (equal populations of all 3 species)
- **0.66:** Two species balanced, one rare
- **0.33:** One species dominant, others exist
- **0.0:** Single species (ecosystem collapse)

### Performance Characteristics

**Computational Complexity:**

Per generation update:
```
O(N) organism updates
  - N organisms process observations
  - Each checks 8 neighbors → O(1) per organism
  
O(G²) scent diffusion
  - G = grid size (50x50 = 2500 cells)
  - 3 diffusion iterations
  - Cost: O(2500 * 3) = O(7500) per generation

O(N) rendering
  - Each organism drawn once
  - Scent overlay: O(80) strongest cells only

Training (periodic):
  - O(E * batch_size * epochs) where E = experience count
  - Default: O(16-500 * 64 * 8) every 20 generations
```

**Memory Usage:**

```
Grid arrays: 50x50 * 3 arrays * 4 bytes = 30 KB
  - plant_scent, herbivore_scent, light_map

Organisms: N * ~500 bytes each
  - Typical N: 100-800 organisms
  - Peak memory: ~400 KB

Neural networks:
  - Hive LSTM: ~80 KB (64 hidden units)
  - Per-organism LSTMs: ~20 KB each
  - Total network memory: 100-500 KB

Experience buffer: up to 500 experiences * 100 bytes = 50 KB

Total: ~1-2 MB typical, 5-10 MB peak
```

**Optimization Opportunities:**

1. **Spatial Indexing:** Use quadtree for neighbor queries (reduces O(N) checks)
2. **Batched Forward Passes:** Process all herbivore brains in single batch
3. **Sparse Scent Calculation:** Only compute scent near organisms
4. **GPU Acceleration:** Move LSTM inference to GPU for large populations
5. **Experience Replay Buffer:** Limit buffer size to prevent memory growth

### Known Behaviors & Edge Cases

**Population Collapse:**
- If predators die out early, herbivores overgraze and destroy plants → total extinction
- If plants cluster too densely, overcrowding kills most → herbivore starvation → predator starvation
- Manual extinction events often cause irreversible cascades

**Hive Learning Failures:**
- With training disabled, predators hunt randomly (success rate ~5%)
- If herbivores evolve very effective escape, predators may never generate positive-reward experiences → hive never learns
- Solution: Occasional manual nutrient spawns keep some organisms alive

**Scent Saturation:**
- In extremely dense populations, scent maps become uniformly bright → organisms lose directional information
- Leads to random-walk behavior even with trained networks

**Boundary Effects:**
- Organisms near grid edges have fewer neighbors → reduced perception
- Corner cells have 3 neighbors vs. 8 for center cells → survival disadvantage
- Plants near edges grow more slowly due to fewer reproduction sites

**Temporal Credit Assignment:**
- REINFORCE rewards immediate actions, but strategic positioning (moving toward future herbivore migration) provides delayed rewards
- Hive struggles to learn multi-step strategies without explicit reward shaping

**Stochastic Extinctions:**
- Even stable ecosystems occasionally collapse due to random fluctuations
- Key species may die simultaneously due to age clustering
- No recovery mechanism for extinct species (except manual spawning)

### Theoretical Foundations

**Lotka-Volterra Dynamics:**

The predator-prey oscillations observed follow modified Lotka-Volterra equations:

```
dP/dt = αP - βPH        (plants grow, eaten by herbivores)
dH/dt = δβPH - γH - ζHR (herbivores eat plants, die naturally, eaten by predators)
dR/dt = εζHR - λR       (predators eat herbivores, die naturally)

Where:
  P = plant population
  H = herbivore population
  R = predator population
  α = plant growth rate (photosynthesis)
  β = herbivore predation rate on plants
  δ = conversion efficiency (plant → herbivore energy)
  γ = herbivore mortality rate
  ζ = predator predation rate on herbivores
  ε = conversion efficiency (herbivore → predator energy)
  λ = predator mortality rate
```

Unlike classical Lotka-Volterra, learning introduces non-constant coefficients:
- β, ζ increase as neural networks learn better hunting strategies
- Oscillations gradually dampen as system learns stable equilibrium
- Extinctions occur when populations hit discrete zero state

**Reinforcement Learning Framework:**

The predator hive implements a REINFORCE policy gradient algorithm, a special case of the general RL problem:

```
π(a|s; θ): Policy network (parameterized by θ)
J(θ) = E[Σ γᵗ r_t]: Expected cumulative reward
∇J(θ) = E[∇ log π(a|s; θ) * R]: Policy gradient

Update rule:
θ ← θ + α * ∇J(θ)
```

**Advantages of REINFORCE here:**
- Simple implementation (single network, no value function)
- Works with continuous high-dimensional state spaces
- Naturally handles stochastic policies (exploration built-in)
- Suitable for episodic tasks (hunt = episode)

**Limitations:**
- High variance gradients → slow convergence
- No bootstrapping → requires complete episodes
- Sample inefficient (experiences discarded after training)

**Evolution vs. Learning:**

The simulation demonstrates two forms of adaptation:

1. **Phylogenetic (Evolutionary):**
   - Herbivore neural weights mutate across generations
   - Selection pressure: organisms with better weights survive longer
   - Timescale: 50-200 generations for noticeable adaptation
   - Mechanism: Variation (mutation) + Selection (survival)

2. **Ontogenetic (Learning):**
   - Predator hive updates weights through gradient descent
   - Improvement within single generation's lifetime
   - Timescale: 20 generations (one training cycle)
   - Mechanism: Error backpropagation + experience replay

**Baldwin Effect:**
Learning can guide evolution—predators that learn to hunt successfully reproduce more, increasing the "learnability" of the hive over time.

### Mathematical Formulations

**Energy Balance Equation:**

For any organism at equilibrium:
```
∫(E_gain - E_loss) dt = 0

Where:
  E_gain = photosynthesis or consumption
  E_loss = metabolism + movement + reproduction

Survival condition:
  E_total(t) > 0 for all t
```

**Population Growth Model:**

Discrete-time population dynamics:
```
N(t+1) = N(t) + B(t) - D(t)

B(t) = Σ [E_i > E_threshold] * reproduction_success
D(t) = Σ [E_i ≤ 0 or age_i > max_age] + predation_deaths

Net growth rate:
r = (B - D) / N
```

**Scent Diffusion (Heat Equation Analogue):**

```
∂S/∂t = D∇²S - λS + Q(x,y,t)

Where:
  S(x,y,t) = scent concentration
  D = diffusion coefficient (related to 0.25 share factor)
  λ = decay rate (0.15)
  Q = source term (organism emissions)

Discrete approximation:
S_i,j^(n+1) = decay * S_i,j^n + (1-decay) * 0.25 * Σ S_neighbors
```

**Policy Gradient Theorem:**

```
∇_θ J(θ) = E_π[∇_θ log π(a|s;θ) Q^π(s,a)]

Approximated by:
∇_θ J(θ) ≈ (1/N) Σ ∇_θ log π(a_i|s_i;θ) R_i

Where R_i is the return (total reward) from state s_i after taking action a_i
```

In this simulation, returns are single-step rewards (no discounting) since hunt events are instantaneous.
