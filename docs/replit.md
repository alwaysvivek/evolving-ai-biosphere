# Evolving AI Biosphere - Website

## Project Overview
This is a professional, interactive website showcasing the technical documentation for the "Evolving AI Biosphere" project. The website presents complex AI and ecosystem simulation concepts in an engaging, visually appealing format.

**Created by:** Vivek Dagar

## Project Structure
- `index.html` - Main HTML structure with all content sections
- `style.css` - Professional, gradient-based styling with modern animations
- `script.js` - Interactive JavaScript features (smooth scrolling, animations, observers)

## Features
- Professional design with refined typography
- Smooth scroll navigation with animated underlines
- Animated sections with intersection observers
- Modern gradient backgrounds (purple/pink spectrum)
- Fully responsive design for all devices
- Enhanced hover effects with smooth transitions
- Syntax-highlighted code blocks
- Professional footer with author credit
- Optimized for readability and visual appeal

## Sections
1. Hero - Project introduction
2. Overview - Five core systems
3. Neural Networks - LSTM architecture details
4. Spatial Grid - Grid system and species parameters
5. Energy System - Energy flow and calculations
6. Chemical Signaling - Scent diffusion
7. Environment - Light maps and global parameters
8. Theory - Lotka-Volterra, RL, Evolution
9. Conclusion - Key takeaways with author credit
